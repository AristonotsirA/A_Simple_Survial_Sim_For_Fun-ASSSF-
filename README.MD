# A Simple Survival Simulator (ASSSF)

간단하게 즐기는 실시간 세계 시뮬레이션. 실제 세계지도 위에서 시나리오별로 진행됩니다.
C# 콘솔(.NET 8)로 제작했습니다.

## 시나리오
| 시나리오 | 상태 | 설명 |
|---|---|---|
| LAST LINE: 좀비 아웃브레이크 | ✅ | '세계 대응 사령부' 사령관이 되어 168개국의 좀비 확산을 막고 치료제를 완성하세요. |

## 실행 방법
- **Visual Studio**: `ZombieOutbreak.sln` 열기 → F5
- **터미널**: `dotnet run --project ZombieOutbreak`
- .NET 8 SDK가 필요합니다.
- 창 크기 **120 x 36 이상**이 필요합니다. Windows Terminal에서 **창을 최대화**하세요.
  (창이 작으면 게임이 안내 화면을 띄우고 기다립니다.)

## 조작
| 키 | 기능 |
|---|---|
| 방향키 | 지도 위 커서 이동 → 커서 아래 나라 선택 |
| Tab | 감염이 심한 나라 순서로 이동 |
| Space | 일시정지 / 재개 |
| + / - | 속도 조절 (3단계) |
| B | 국경 봉쇄 / 개방 |
| M | 방역 작전 (4주간 감염 억제 + 좀비 처치) |
| N | 전술 핵 (확인 후 실행) |
| R | 치료제 연구 투자 |
| H | 도움말 |
| Esc | 메뉴 (포기하기) |

시간은 자동으로 흐르며(하루 단위), 매주 일정 확률로 사건 카드가 뜨면 자동으로 멈춥니다.

**승리**: 치료제 100% 완성 후 좀비 소탕 · **패배**: 생존자 40% 미만(문명 붕괴) 또는 신뢰도 0(해임)

## 코드 구조
```
ZombieOutbreak/
├─ Core/      데이터 모델 (Country, World, WorldMap, Difficulty) ─ 무엇이 있는가
├─ Data/      국가 표 · 지도 격자 · World 생성기                 ─ 처음 세계를 어떻게 만드는가
├─ Systems/   규칙 엔진 (Simulation, Actions, EventDeck)          ─ 세계가 어떻게 변하는가
├─ UI/        화면 버퍼 · 게임 화면 · 입력 · 메뉴                  ─ 어떻게 보여주고 조작하는가
├─ Game.cs    실시간 게임 루프
└─ Program.cs 진입점
```
UI는 Systems를 호출만 하고, Systems는 UI를 전혀 모릅니다.
덕분에 같은 규칙 엔진을 화면 없이 테스트하거나 Unity·서버로 옮길 수 있습니다.

## 데이터 출처
- 세계지도: [Natural Earth](https://www.naturalearthdata.com/) 1:110m 국가 경계 (퍼블릭 도메인)를 116 x 26 격자로 변환
- 국가별 인구: 2024년 기준 근사치
- 감염 모델은 게임용으로 단순화한 것입니다.
